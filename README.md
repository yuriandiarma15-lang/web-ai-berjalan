
# XAU AI Virtual Trading Office

Landing page 3D simulasi kantor trading XAU AI.

## Fitur
- 3D virtual trading office
- XAU AI branding
- Team Leader dan empat AI Analyst
- Simulated XAUUSD chart M30, M15, M5, M1
- Animated team communication
- WIB clock
- Hourly visual briefing
- Responsive landing page

## Menjalankan lokal

Install Node.js 20 atau lebih baru.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy Railway

1. Upload repository ke GitHub.
2. Railway → New Project.
3. Deploy from GitHub Repo.
4. Pilih repository ini.
5. Railway menggunakan Dockerfile untuk build.
6. Generate domain dari Railway Networking.

Website ini hanya simulasi visual. Tidak menjalankan analisis market dan tidak mengirim signal Telegram.
